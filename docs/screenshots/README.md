# Screenshot locations

No repository screenshots are available yet. Optional real-game captures can be added here:

- `offered.png`: Offered table with useful real records and the toolbar visible.
- `history.png`: completed subsidy overview.
- `native-detail.png`: the game's detail window opened from a row.
- `empty.png`: the compact preset with an empty overview.

If updating the Mod Hub gallery, use a representative cover at `_metadata/0.png` and additional numbered PNGs. Preserve the existing listing and gallery when no replacement images are supplied. The official metadata guide recommends 1920×1080 images. Use real captures, never mock fixtures presented as gameplay. See [TF3 mod definition](https://wiki.transportfever3.com/doku.php?id=modding:general:moddefinition).

Repository screenshots stay outside the runtime archive. Approved numbered `_metadata` images can be included as publication metadata by the package builder.
